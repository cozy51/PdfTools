# PDF 回転・削除・結合

複数PDFの順番を調整して結合し、ページの並べ替え・個別回転・複数選択削除をして保存できる、独立した静的Webアプリです。拡張機能のインストールやサーバー側のPDF処理は必要ありません。PDFはブラウザー内だけで処理され、外部サーバーには送信されません。

現在のバージョンは `1.4.2` です。

## 起動方法

ES ModulesとWeb Workerを使用するため、ファイルを直接開くのではなくHTTPサーバーから配信してください。

Python 3がある場合は、プロジェクトのルートで次を実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザーで <http://localhost:8000/> を開きます。外部への公開時は、このディレクトリをそのまま任意の静的ホスティングサービスへ配置できます。ビルド処理や環境変数は不要です。

## 使い方

1. 1個または複数のPDFを画面へドロップするか「PDFを選択」を押します。
2. 「結合するPDF」でファイルをドラッグするか上下矢印を押し、連結順を調整します。
3. ページプレビュー上部のグリップをドラッグし、ページ単位の順序を調整します。異なるPDF間でも移動できます。
4. 各ページの下にある左右の回転ボタンで、必要なページだけ回転します。
5. 削除するページのプレビューをクリックして複数選択し、「選択ページを削除」を押します。
6. 「PDFを結合して保存」または「編集後のPDFを保存」を押すと、ブラウザーのダウンロード先へ保存されます。

削除直後は「削除を戻す」で直前の削除を取り消せます。元のPDFは上書きされません。単独ファイルには `_edited`、複数ファイルには `_merged` が付いた名前で保存されます。

## 対応範囲

- PCとタブレットの画面幅に対応したプレビュー
- 複数PDFの追加、ドラッグまたは矢印による並べ替え、連結保存
- ページプレビューのドラッグによる、PDFをまたいだ自由なページ順変更
- 各ページに独立した左右90度回転ボタン
- ページの複数選択、一括削除、直前の削除の取り消し
- すべてのページをまとめて選択、選択解除
- 表示範囲に近いページだけを描画する軽量なプレビュー
- 端末内だけでのPDF処理とブラウザー標準のダウンロード
- 対応ブラウザーでのホーム画面／アプリ一覧への追加

パスワード保護PDFには対応していません。また、電子署名、しおり、一部のフォーム構造などは、ページ編集や結合によって失われることがあります。非常に大きいPDFや多数のファイルでは処理に時間やメモリが必要になることがあります。

## 構成

- `index.html`, `editor.css`, `editor.js`: Webアプリの画面と操作
- `app.webmanifest`: インストール可能なWebアプリとしての表示情報
- `pdf-core.js`: 回転・ファイル名・表示情報のロジック
- `vendor/pdf-lib.min.js`: PDFの読み込み・保存処理
- `vendor/pdf.min.mjs`, `vendor/pdf.worker.min.mjs`: ページ内容のプレビュー描画
- `tests/pdf-core.test.js`: 回転、結合、保存の簡易テスト

## 開発者向け確認

Node.jsが利用できる環境で次を実行します。

```bash
node tests/pdf-core.test.js
```
