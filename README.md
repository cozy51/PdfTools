# PDF 回転・削除・結合

Microsoft Edgeで複数PDFの順番を調整して結合し、ページの個別回転や複数選択削除をして保存するManifest V3拡張機能です。PDFはブラウザー内だけで処理され、外部サーバーには送信されません。

現在のバージョンは `1.4.0` です。拡張機能アイコンをクリックすると、広い専用タブで編集画面が開きます。同じタブを開いている間は、別のタブへ移動して戻っても読み込んだPDFと編集状態が維持されます。画面全体の文字と操作領域を大きくし、ページ単位のドラッグ並べ替えにも対応しています。

## 配布用マニュアル

初めて使う方には、[PDF編集ツール 使い方マニュアル](output/pdf/PDF編集ツール_使い方マニュアル_v1.4.0.pdf)を一緒にお渡しください。Edgeへの追加方法から、ファイル・ページの並べ替え、回転、削除、保存、トラブル対処まで画面付きで説明しています。

## Edgeへの追加方法

1. Edgeで `edge://extensions/` を開きます。
2. 左側の「開発者モード」をオンにします。
3. 「展開して読み込み」を押します。
4. この `PdfTools` フォルダーを選択します。
5. ツールバーの拡張機能メニューから「PDF 回転・削除・結合」をクリックします。
6. 新しい専用タブに編集画面が開きます。編集タブが既にある場合は、そのタブへ戻ります。

## 使い方

1. 拡張機能アイコンから専用タブを開き、1個または複数のPDFをドロップするか「PDFを選択」を押します。
2. 「結合するPDF」でファイルをドラッグするか上下矢印を押し、連結順を調整します。
3. ページプレビュー上部のグリップをドラッグし、ページ単位の順序を調整します。異なるPDF間でも移動できます。
4. 各ページの下にある左右の回転ボタンで、必要なページだけ回転します。
5. 削除するページのプレビューをクリックして複数選択し、「選択ページを削除」を押します。
6. 「PDFを結合して保存」または「編集後のPDFを保存」を押し、保存先を選びます。

削除直後は「削除を戻す」で直前の削除を取り消せます。元のPDFは上書きされません。単独ファイルには `_edited`、複数ファイルには `_merged` が付いた名前で保存されます。

## 対応範囲

- 画面幅に応じて広がる大きな多列プレビュー
- 見出し、説明、ファイル名、ページ番号、操作ボタンの読みやすい大きな表示
- ポップアップではなく、ブラウザー幅を使える専用編集タブ
- 編集タブを開いている間のファイル・並び順・ページ編集状態の維持
- 複数PDFの追加、ドラッグまたは矢印による並べ替え、連結保存
- ページプレビューのドラッグによる、PDFをまたいだ自由なページ順変更
- 各ページに独立した左右90度回転ボタン
- ページの複数選択、一括削除、直前の削除の取り消し
- すべてのページをまとめて選択、選択解除
- 表示範囲に近いページだけを描画する軽量なプレビュー
- ローカル処理と名前を付けて保存

パスワード保護PDFには対応していません。また、電子署名、しおり、一部のフォーム構造などは、ページ編集や結合によって失われることがあります。非常に大きいPDFや多数のファイルでは処理に時間やメモリが必要になることがあります。

## 構成

- `manifest.json`: Edge/Chromium向けManifest V3設定
- `background.js`: 拡張機能アイコンから編集タブを開き、既存タブへ戻す処理
- `editor.html`, `editor.css`, `editor.js`: 専用編集タブの画面と操作
- `pdf-core.js`: 回転・ファイル名・表示情報のロジック
- `vendor/pdf-lib.min.js`: PDFの読み込み・保存処理
- `vendor/pdf.min.mjs`, `vendor/pdf.worker.min.mjs`: ページ内容のプレビュー描画
- `tests/pdf-core.test.js`: 回転と保存の簡易テスト

## 開発者向け確認

Node.jsが利用できる環境で次を実行します。

```powershell
node tests/pdf-core.test.js
```
