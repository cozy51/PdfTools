# PDF 回転・削除・結合・書き込み

複数PDFの順番を調整して結合し、ページの並べ替え・個別回転・複数選択削除ができる、独立した静的Webアプリです。ページを開いて拡大表示し、編集モードでテキストの挿入、ペンでの描画、蛍光ペンでの強調もできます。拡張機能のインストールやサーバー側のPDF処理は必要ありません。PDFはブラウザー内だけで処理され、外部サーバーには送信されません。

現在のバージョンは `1.7.0` です。

## 起動方法

### Webアプリとして使う（推奨）

配信済みのURLを開くだけで使えます。ビルド処理は不要で、このディレクトリをそのまま静的ホスティングへ配置します。

Vercelの場合は、GitHubリポジトリを連携し「Framework Preset: Other」を選び、Build CommandとOutput Directoryは空のままにします。以降はpushするたびに自動デプロイされます。

初回アクセス後は、ブラウザーのアドレスバー右側またはメニューから**アプリとしてインストール**できます。インストールするとアイコンから独立したウィンドウで起動し、Service Workerが必要なファイルを保存するため**オフラインでも動作します**。ローカルサーバーの起動操作は不要になります。

PDFの処理はすべてブラウザー内で完結し、外部への通信は行いません。配信されるのは静的ファイルだけで、PDFがサーバーへ送られる経路はありません。

### Windows

`start.cmd` をダブルクリックします。ローカルサーバーが起動し、ブラウザーが自動的に開きます。終了するときは、開いた黒いウィンドウを閉じるか Ctrl+C を押します。

### Windows以外、または手動で起動する場合

プロジェクトのルートで次を実行します。ポート番号を指定したい場合は `python3 serve.py 8080` のように渡します。

```bash
python3 serve.py
```

なお `localhost` と `127.0.0.1` では Service Worker を登録しません。ファイルがすでに手元にあるためオフライン対応の利点がなく、編集したファイルがキャッシュから返って古い表示になるのを防ぐためです。

### index.html を直接開けない理由

このアプリはES ModulesとWeb Workerを使用します。`file://` で開いた場合、ブラウザーは別オリジン扱いでモジュールの読み込みを拒否するため、`editor.js` が実行されず、ドロップもボタンも反応しません。画面自体は表示されるので故障のように見えますが、ローカルサーバー経由で開けば解決します。直接開いた場合は、その旨と対処方法を画面に表示します。

`serve.py` は、Windowsのレジストリ設定によって `.js` や `.mjs` が `text/plain` として配信されモジュールの読み込みが失敗するのを防ぐため、MIMEタイプを明示しています。`python3 -m http.server` ではこの問題が起こる可能性があるため、`serve.py` の使用を推奨します。

## 使い方

1. 1個または複数のPDFを画面へドロップするか「PDFを選択」を押します。
2. 「結合するPDF」でファイルをドラッグするか上下矢印を押し、連結順を調整します。
3. ページプレビュー上部のグリップをドラッグし、ページ単位の順序を調整します。異なるPDF間でも移動できます。
4. 各ページの下にある左右の回転ボタンで、必要なページだけ回転します。
5. 削除するページのプレビューをクリックして複数選択し、「選択ページを削除」を押します。
6. ページをダブルクリックするか「開いて編集」を押すと、そのページを大きく開きます。左の一覧でPDF名をダブルクリックすると、そのPDFの先頭ページが開きます。
7. 「PDFを結合して保存」または「編集後のPDFを保存」を押すと、ブラウザーのダウンロード先へ保存されます。

## ページを開いて書き込む

開いたページは最初「閲覧モード」です。「編集モードにする」を押すと、上部に道具が並びます。

| 道具 | できること |
| --- | --- |
| 選択 | 書き込みをクリックで選び、ドラッグで移動します。文字はダブルクリックで書き直せます。Deleteキーで削除します |
| テキスト | ページ上をクリックした場所に文字を入力します。改行もできます。Escで取り消し、Ctrl+Enterまたは枠の外をクリックで確定します |
| ペン・フリー | ドラッグでなぞった通りに線を描きます |
| ペン・直線 | ドラッグした始点と終点を結ぶ直線を描きます |
| 蛍光ペン・フリー | ドラッグでなぞった部分を半透明の色で塗ります。下の文字は消えません |
| 蛍光ペン・直線 | 半透明の帯を直線で引きます |

直線は、引いた向きがほぼ水平またはほぼ垂直（7度以内）のときだけ、水平・垂直へ揃えます。始点はそのままに、終点をその軸へ下ろします。はっきり斜めに引いた線は補正しません。

色と太さは、ペンと蛍光ペンでそれぞれ別に覚えます。道具を選び直すと、その道具に設定した色と太さへ戻ります。文字サイズはテキスト用です。

拡大しているときは、ページの上を**右ドラッグ**すると表示位置をつかんで動かせます。スクロールバーまでカーソルを運ぶ必要はありません。この操作に使うため、ページの上では右クリックのメニューを表示しません。「元に戻す」で直前の操作を、「すべて消去」でそのページの書き込みをまとめて取り消せます。表示倍率は「＋」「－」「全体表示」で変えられます。「前のページ」「次のページ」で編集モードのまま移動できます。

書き込みはページに紐づきます。ページを回転しても並べ替えても内容と同じ位置に残り、保存したPDFにも同じ位置で書き込まれます。書き込みのあるページには、一覧で「書き込みあり」と表示されます。

なお、挿入した文字は画像としてPDFへ書き込みます。日本語を含むどの文字でも画面と同じ見た目で保存できる代わりに、保存後のPDFで文字を選択したり検索したりはできません。

削除直後は「削除を戻す」で直前の削除を取り消せます。元のPDFは上書きされません。単独ファイルには `_edited`、複数ファイルには `_merged` が付いた名前で保存されます。

## 対応範囲

- PCとタブレットの画面幅に対応したプレビュー
- 複数PDFの追加、ドラッグまたは矢印による並べ替え、連結保存
- ページプレビューのドラッグによる、PDFをまたいだ自由なページ順変更
- 各ページに独立した左右90度回転ボタン
- ページの複数選択、一括削除、直前の削除の取り消し
- ページを開いての拡大表示と、編集モードでのテキスト挿入・ペン・蛍光ペンの描画
- ほぼ水平・垂直な直線の自動補正
- 拡大時の右ドラッグによる表示位置の移動
- 書き込みの選択、移動、削除、取り消し、道具ごとの色と太さの指定
- すべてのページをまとめて選択、選択解除
- 表示範囲に近いページだけを描画する軽量なプレビュー
- 端末内だけでのPDF処理とブラウザー標準のダウンロード
- 対応ブラウザーでのアプリとしてのインストールと、インストール後のオフライン動作

パスワード保護PDFには対応していません。書き込みは保存するまでこのブラウザーの中だけに残るため、保存せずにページを閉じると失われます。また、電子署名、しおり、一部のフォーム構造などは、ページ編集や結合によって失われることがあります。非常に大きいPDFや多数のファイルでは処理に時間やメモリが必要になることがあります。

## 構成

- `start.cmd`: Windows用の起動ファイル（ダブルクリックでサーバー起動とブラウザー表示）
- `serve.py`: ローカルHTTPサーバー。空きポートを探して配信し、ブラウザーを開く
- `index.html`, `editor.css`, `editor.js`: Webアプリの画面と操作
- `app.webmanifest`: インストール可能なWebアプリとしての表示情報
- `sw.js`: オフライン対応のService Worker。**配信ファイルを更新したら `CACHE_NAME` を上げる**
- `vercel.json`, `.vercelignore`: Vercelでの配信設定（MIMEタイプと配信対象の指定）
- `pdf-core.js`: 回転・ファイル名・表示情報・ページ座標変換・直線の補正・書き込みの描き込みのロジック
- `page-editor.js`: ページを開いて編集するモードと、書き込みの保持・描画
- `vendor/pdf-lib.min.js`: PDFの読み込み・保存処理
- `vendor/pdf.min.mjs`, `vendor/pdf.worker.min.mjs`: ページ内容のプレビュー描画
- `tests/pdf-core.test.js`: 回転、結合、保存、座標変換、直線の補正、書き込みの簡易テスト

## 開発者向け確認

Node.jsが利用できる環境で次を実行します。

```bash
node tests/pdf-core.test.js
```
